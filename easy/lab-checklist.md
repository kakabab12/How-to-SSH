<a id="before"></a>
## 1. 🎒 연구실 가기 전에 챙길 것

- [ ] **노트북** + **충전기**
- [ ] **구글 계정 비밀번호** (Tailscale 로그인에 써요. 두 컴퓨터 모두 같은 계정!)
- [ ] **연구실 PC 로그인 비밀번호**
  - 연구실 PC가 윈도우이고 **이메일로 로그인**한다면 → **Microsoft 계정 비밀번호** (PIN 말고!). 기억 안 나면 미리 `account.microsoft.com`에서 재설정해 두세요.
- [ ] **메모할 것** (종이나 휴대폰 메모 앱) → [메모 카드 양식](00-before-you-start.md#memo)
- [ ] **시간 40분** + 여유 시간
- [ ] (가능하면) 교수님이나 전산팀에 **원격 접속 프로그램 설치 괜찮은지** 확인
- [ ] 연구실 PC와 노트북이 **인터넷에 연결**되어 있는지

### ✅ 최종 확인 — 이게 다 되면 집에 가도 돼요!

- [ ] 🏫 **연구실 PC**를 **다시 시작**하고, **아무것도 건드리지 않고** 3분 기다렸어요.
- [ ] 💻 **노트북**에서 **RustDesk**로 연구실 화면이 보여요.
  - 연구실 PC가 우분투 → **바탕화면**이 보여야 해요.
  - 연구실 PC가 윈도우 → **로그인 화면**이 보이면 성공이에요. RustDesk 창 안에서 로그인해 보세요.
- [ ] 💻 **노트북**에서 `ssh 사용자명@100.x.x.x` 접속이 돼요.
- [ ] 💻 노트북을 **휴대폰 핫스팟**에 연결해도 RustDesk 접속이 돼요. (= 학교 밖에서도 된다는 뜻)
- [ ] 📝 메모 카드에 **IP, 사용자명, RustDesk 비밀번호**를 적었어요.
- [ ] 🗒️ 연구실 PC에 **"원격으로 쓰는 중이에요. 전원을 끄지 말아 주세요 🙏"** 메모를 붙였어요.
- [ ] 🖥️ **모니터만** 껐어요. (본체는 켜 둬요!)

<a id="leaving"></a>
## 3. 🚪 연구실을 떠날 때마다 (매일 1분)

설정이 끝난 뒤, **연구실 PC를 직접 쓰다가 퇴근할 때마다** 확인하세요.

### 🐧 연구실 PC가 우분투일 때

- [ ] ❌ **전원 끄기** 누르지 않기 → 본체는 켜 둬요.
- [ ] ❌ **로그아웃** 하지 않기 → 로그인된 상태 **그대로** 두고 가요.
  > 💬 자동 로그인은 **컴퓨터가 켜질 때만** 동작해요. 로그아웃하면 로그인 화면에서 멈춰서 **RustDesk로 화면을 볼 수 없어요.** (SSH는 돼요)
- [ ] 🖥️ **모니터만** 끄기
- [ ] ⏳ 오래 걸리는 작업을 돌려 놓았다면 **tmux 안에서** 돌리고 있는지 확인 → [tmux 사용법](../guides/05-tips.md#tmux)
- [ ] 🌐 인터넷(랜선, 와이파이)이 연결되어 있는지 확인

### 🪟 연구실 PC가 윈도우일 때

- [ ] ❌ **시스템 종료** 누르지 않기 → 본체는 켜 둬요.
- [ ] ⚠️ **"업데이트 및 종료"** 를 누르지 않기! 이름은 비슷하지만 **컴퓨터가 꺼져요.**
  - 업데이트를 하고 싶으면 **"업데이트 및 다시 시작"** 을 누르세요. (다시 켜지니까 괜찮아요)
- [ ] 🔒 자리를 비울 때는 **잠금**(`Win` + `L`)을 추천해요.
  - 잠금 상태에서도 RustDesk와 SSH 접속이 돼요.
  - 로그아웃해도 접속은 되지만, **열어 둔 프로그램이 모두 꺼져요.**
- [ ] 🖥️ **모니터만** 끄기
- [ ] ⏳ 오래 걸리는 작업이 있으면 **업데이트 일시 중지**: 설정 → Windows 업데이트 → **업데이트 일시 중지**
- [ ] 🌐 인터넷(랜선, 와이파이)이 연결되어 있는지 확인

<a id="at-lab"></a>
## 4. 🧑‍💻 연구실에서 PC를 직접 쓸 때 주의할 점

평소처럼 연구실 PC를 써도 괜찮아요. 다만 **아래 설정은 건드리지 마세요.** 바꾸면 집에서 접속이 안 돼요.

| 건드리지 말 것 | 이유 |
|---|---|
| **Tailscale** 로그아웃, 종료 | 비밀 통로가 끊겨요 |
| **절전 모드** 다시 켜기 | 잠들면 밖에서 깨울 수 없어요 |
| **RustDesk** 삭제, 설정 변경 | 화면 원격 접속이 안 돼요 |
| (우분투) **자동 로그인** 끄기 | 재부팅 후 화면 원격 접속이 안 돼요 |
| (우분투) 로그인 화면 톱니바퀴(⚙)에서 **"Wayland"** 고르기 | RustDesk 화면이 검게 나와요 |
| (윈도우) **Windows Hello 로그인만 허용** 다시 켜기 | 원격 로그인에 비밀번호를 못 써요 |
| **컴퓨터 비밀번호 변경** | 바꿨다면 **그 자리에서 바로** 노트북으로 SSH 접속 테스트 |

💡 알아두면 좋은 것
- 집에서 RustDesk로 접속해 있으면 **연구실 모니터에 내 화면이 똑같이 보이고, 마우스가 저절로 움직여요.** 놀라지 마세요. 😄
- 연구실 동료에게 "**이 PC는 원격으로 쓰니까 끄지 말아 주세요**"라고 한 번 말해 두면 좋아요.
- 연구실이 **정전 점검**을 한다고 하면, 다음 날 연구실 PC가 켜져 있는지 확인하세요.

## 6. 🆘 집에서 접속이 안 됐을 때 → 다음에 연구실 가서 확인할 것

집에서 안 됐다고 당황하지 마세요. 다음에 연구실에 가면 **위에서부터 하나씩** 확인하세요.

### ① 연구실 PC가 켜져 있나요?
- [ ] 모니터를 켜서 화면이 나오는지 확인
- [ ] 화면이 안 나오면 본체 전원 버튼을 **한 번 짧게** 눌러 보기 (잠들어 있었다면 깨어나요)
  - 켜져 있었는데 잠든 거라면 → **절전 설정이 다시 켜진 것**이에요. 가이드의 절전 끄기 단계를 다시 하세요.
  - 아예 꺼져 있었다면 → 누가 껐거나 정전이었어요. 메모를 붙이고, BIOS 설정도 고려해 보세요. → [자세한 설명](../guides/07-cautions.md#power)

### ② 인터넷이 연결되어 있나요?
- [ ] 연구실 PC에서 브라우저로 아무 사이트나 열어 보기

### ③ Tailscale이 켜져 있나요?
🐧 **우분투**: 터미널(`Ctrl`+`Alt`+`T`)
```bash
tailscale status
```
- `Logged out` 이나 `stopped`가 보이면 → `sudo tailscale up` 으로 다시 로그인

🪟 **윈도우**: 작업 표시줄의 Tailscale 아이콘 확인 → 로그아웃되어 있으면 **Log in**
- 다시 로그인했다면 [Disable key expiry](04-windows-to-ubuntu.md#step3)도 다시 확인하세요.

### ④ SSH가 켜져 있나요?
🐧 **우분투**
```bash
systemctl is-active ssh
```
→ `active`가 아니면: `sudo systemctl enable --now ssh`

🪟 **윈도우** (터미널)
```powershell
Get-Service sshd
```
→ `Running`이 아니면: 관리자 터미널에서 `Start-Service sshd`

### ⑤ (우분투) 로그인 화면에 멈춰 있나요?
- [ ] 로그인 화면이 떠 있으면 → **자동 로그인이 꺼진 것** 또는 **누가 로그아웃한 것**이에요. 로그인한 뒤 [자동 로그인](04-windows-to-ubuntu.md#step7)을 다시 확인하세요.
- [ ] 로그인한 뒤 터미널에서 `echo $XDG_SESSION_TYPE` → `x11`인지 확인하세요.

### ⑥ RustDesk가 설치되어 있고 설정이 그대로인가요?
- [ ] RustDesk 실행 → 설정 → 보안 → **IP 직접 접근 허용**이 체크되어 있는지
- [ ] 영구 비밀번호가 그대로인지 (헷갈리면 새로 설정하고 메모 카드 수정)

### ⑦ 다 확인했으면
- [ ] 노트북으로 **그 자리에서** RustDesk와 SSH 접속 테스트
- [ ] 그래도 안 되면 → [문제 해결 모음](../guides/08-troubleshooting.md)

## 🖥️ 컴퓨터 기본

| 단어 | 쉬운 뜻 |
|---|---|
| **터미널** | 마우스 대신 **글자로 컴퓨터에 명령하는 창**이에요. 우분투는 `Ctrl`+`Alt`+`T`, 윈도우는 시작 버튼 오른쪽 클릭 → 터미널로 열어요. |
| **명령어** | 터미널에 입력하는 **글자로 된 지시**예요. 예: `whoami` = "나 누구야?" |
| **프롬프트** | 터미널에서 **입력을 기다리는 줄**이에요. `hong@lab-pc:~$` 나 `PS C:\Users\hong>` 처럼 생겼어요. 이게 보이면 다음 명령을 쳐도 돼요. |
| **PowerShell** | 윈도우의 터미널 프로그램 이름이에요. |
| **관리자 권한** | 컴퓨터의 **중요한 설정을 바꿀 수 있는 권한**이에요. 윈도우에서는 "터미널(관리자)"로 열어야 해요. |
| **sudo** | 우분투에서 **관리자 권한으로 실행**하라는 뜻이에요. 명령어 앞에 붙이면 비밀번호를 물어봐요. |
| **사용자명** | 컴퓨터에 로그인하는 **계정 이름**이에요. 터미널에 `whoami`를 치면 나와요. |
| **재부팅** | 컴퓨터를 **껐다가 다시 켜는 것**(다시 시작)이에요. 원격에서는 괜찮아요. |
| **시스템 종료** | 컴퓨터를 **완전히 끄는 것**이에요. ⚠️ 원격에서 하면 **다시 켤 수 없어요.** |
| **절전 모드** | 한동안 안 쓰면 컴퓨터가 **잠드는 기능**이에요. 원격으로 쓰려면 꺼야 해요. |
| **자동 로그인** | 컴퓨터를 켜면 **비밀번호 없이 바로 바탕화면까지** 가는 기능이에요. |

## 🌐 네트워크

| 단어 | 쉬운 뜻 |
|---|---|
| **IP 주소** | 인터넷에서 컴퓨터를 찾아가는 **집 주소** 같은 숫자예요. 예: `100.64.12.34` |
| **Tailscale** | 내 컴퓨터들끼리 **비밀 통로(VPN)** 를 만들어 주는 무료 프로그램이에요. 학교 방화벽이 있어도 연구실 PC를 찾아갈 수 있어요. |
| **Tailscale IP** | Tailscale이 각 컴퓨터에 주는 **`100.`으로 시작하는 고정 주소**예요. 어디서 접속해도 바뀌지 않아요. |
| **VPN** | 인터넷 위에 만든 **나만의 비밀 통로**예요. |
| **방화벽** | 밖에서 들어오는 접속을 **막는 문지기**예요. 학교 네트워크에는 보통 방화벽이 있어요. |
| **핫스팟** | 휴대폰 데이터를 노트북에서 와이파이처럼 쓰는 기능이에요. "학교 밖에서도 되는지" 테스트할 때 써요. |
| **포트** | 한 컴퓨터 안에 있는 **여러 개의 문 번호**예요. SSH는 22번, 윈도우 원격 데스크톱은 3389번 문을 써요. |

## 🔌 원격 접속

| 단어 | 쉬운 뜻 |
|---|---|
| **원격 접속** | 멀리 있는 컴퓨터를 **내 컴퓨터에서 조종하는 것**이에요. |
| **원격 컴퓨터 (서버, 호스트)** | 접속**당하는** 컴퓨터예요. 이 가이드에서는 **연구실 PC**예요. |
| **내 컴퓨터 (클라이언트)** | 접속**하는** 컴퓨터예요. 이 가이드에서는 **내 노트북이나 집 PC**예요. |
| **SSH** | 원격 컴퓨터에 **명령어로 접속하는 방법**이에요. 화면은 안 보이고 검은 창에 글자만 보여요. 빠르고 안정적이에요. |
| **원격 데스크톱** | 원격 컴퓨터의 **바탕화면을 그대로 보면서** 마우스와 키보드로 조작하는 방법이에요. |
| **RustDesk** | 원격 데스크톱 **무료 프로그램**이에요. 윈도우와 우분투 모두 돼요. 쉬운 가이드에서는 이것만 써요. |
| **RDP** | 윈도우에 기본으로 들어 있는 원격 데스크톱 방식이에요. 윈도우 **Pro** 이상에서만 접속받을 수 있어요. |
| **mstsc** | 윈도우의 "원격 데스크톱 연결" 프로그램이에요. `Win`+`R` → `mstsc`로 열어요. |
| **영구 비밀번호** | RustDesk에서 **바뀌지 않게 정해 두는 비밀번호**예요. 원격으로 접속할 때 이걸 입력해요. 컴퓨터 로그인 비밀번호와는 **달라요.** |
| **ID (RustDesk)** | RustDesk가 각 컴퓨터에 주는 번호예요. 이 가이드에서는 ID 대신 **Tailscale IP**로 접속해요. |

## 🐧 우분투

| 단어 | 쉬운 뜻 |
|---|---|
| **우분투 (Ubuntu)** | 무료 운영체제(리눅스)의 한 종류예요. 연구실 서버에 많이 써요. |
| **apt** | 우분투의 **앱 설치 도구**예요. `sudo apt install 프로그램이름`으로 설치해요. |
| **.deb 파일** | 우분투용 **설치 파일**이에요. 윈도우의 `.exe` 같은 거예요. |
| **Wayland / Xorg (x11)** | 우분투가 **화면을 그리는 방식** 두 가지예요. 우분투 22.04는 기본이 Wayland인데, RustDesk는 **Xorg**에서 잘 돼요. 겉보기엔 거의 똑같아요. |
| **홈 폴더 (`~`)** | 내 파일이 있는 기본 폴더예요. `/home/사용자명`이에요. |

## 🪟 윈도우

| 단어 | 쉬운 뜻 |
|---|---|
| **Microsoft 계정** | **이메일 주소로 로그인**하는 윈도우 계정이에요. 원격 접속 비밀번호는 이 이메일 계정의 비밀번호예요. |
| **로컬 계정** | 이메일 없이 그 컴퓨터에서만 쓰는 계정이에요. |
| **PIN** | 윈도우에 로그인할 때 쓰는 **짧은 숫자**예요. ⚠️ 원격 접속(SSH)에는 **못 써요.** |
| **Windows Hello** | PIN, 얼굴, 지문으로 로그인하는 윈도우 기능이에요. |
| **OpenSSH 서버** | 윈도우가 **SSH 접속을 받을 수 있게** 해 주는 기능이에요. 따로 켜야 해요. |
| **Run unattended** | Tailscale 설정이에요. **아무도 로그인하지 않아도** Tailscale이 켜지게 해요. |
| **에디션 (Home / Pro)** | 윈도우의 종류예요. 설정 → 시스템 → 정보에서 확인할 수 있어요. |

## 🔑 조금 더 알면 좋은 것

| 단어 | 쉬운 뜻 |
|---|---|
| **SSH 키** | 비밀번호 대신 쓰는 **디지털 열쇠**예요. 설정하면 비밀번호 없이 접속돼요. **개인키**(내가 갖고 있는 열쇠, 절대 공유 금지)와 **공개키**(원격 컴퓨터에 등록하는 자물쇠)가 한 쌍이에요. |
| **tmux** | SSH가 끊겨도 **작업이 계속 돌게** 해 주는 우분투 프로그램이에요. 딥러닝 학습 돌릴 때 필수예요. |
| **VS Code Remote-SSH** | VS Code 확장 프로그램이에요. 연구실 PC의 코드를 **내 노트북 VS Code에서 바로 편집**할 수 있어요. |
| **scp** | SSH로 **파일을 복사**하는 명령어예요. |
| **키 만료 (key expiry)** | Tailscale이 몇 달마다 다시 로그인하라고 하는 기능이에요. 연구실 PC는 꺼 둬요. |

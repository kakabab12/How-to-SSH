# 🧭 Tailscale 없이 접속하기

> Tailscale을 쓸 수 없거나 쓰고 싶지 않을 때의 방법입니다.
> 어떤 방법이든 각 가이드(01~04)에 나오는 `100.x.x.x`를 **아래 방법으로 얻은 IP**로 바꾸면 나머지 과정은 똑같습니다.

[← 전체 목차로 돌아가기](../README.md)

---

## A. 같은 네트워크 안에 있을 때 (같은 연구실, 같은 공유기)

Tailscale 없이 **내부 IP**로 바로 접속할 수 있습니다.

1. 원격 컴퓨터의 내부 IP 확인
   - Ubuntu: `hostname -I`
   - Windows: `ipconfig` → `IPv4 주소`
2. 접속
   ```bash
   ssh 사용자명@192.168.x.x
   ```

⚠️ 알아두기
- 공유기가 IP를 자동으로 주기 때문에(DHCP) **재부팅하면 IP가 바뀔 수 있습니다.** 공유기 설정에서 "고정 IP 할당(DHCP 예약)"을 하거나 Tailscale을 쓰세요.
- 학교 네트워크는 같은 건물이어도 층이나 방마다 네트워크가 나뉘어 있어서 **서로 접속이 안 될 수 있습니다.**

---

## B. 학교 VPN을 쓸 수 있을 때 (규정상 가장 안전)

1. 집이나 노트북에서 **학교 VPN에 연결**합니다. (학교 전산팀 안내에 따라 VPN 프로그램 설치)
2. 연구실 PC의 **학교 내부 IP**로 접속합니다.
   ```bash
   ssh 사용자명@10.x.x.x
   ```
3. 연구실 PC의 IP가 바뀌지 않도록 전산팀에 **고정 IP**를 요청하세요.

- 장점: 학교가 공식으로 지원하는 방법이라 규정 걱정이 없습니다.
- 단점: 학교 VPN이 느리거나, 동시 접속 제한이 있거나, 특정 포트(SSH 22, RDP 3389)를 막아 두었을 수 있습니다.

---

## C. 공인 IP + 포트포워딩 (비추천)

연구실 PC가 **공인 IP를 직접 받거나**, **공유기 관리자 권한**이 있을 때만 가능합니다.

1. 공유기 관리 페이지 → 포트포워딩 → 외부 포트(예: `2222`) → 내부 IP `192.168.x.x`의 `22` 포트
2. 외부에서 접속
   ```bash
   ssh -p 2222 사용자명@공인IP
   ```

⚠️ **반드시 지켜야 할 것**
- 인터넷에 포트를 열면 **몇 분 안에 전 세계에서 무작위 로그인 시도**가 들어옵니다.
- **키 인증만 허용**하고 비밀번호 로그인은 끄세요. → [06-security.md](06-security.md#disable-password)
- Ubuntu라면 **fail2ban**을 설치하세요.
- **RDP(3389)와 RustDesk 포트는 절대 인터넷에 직접 열지 마세요.** 원격 데스크톱은 SSH 터널을 거치게 하세요.
  ```bash
  ssh -p 2222 -L 3389:localhost:3389 사용자명@공인IP
  # 그다음 원격 데스크톱 연결에서 localhost 로 접속
  ```
- 학교 네트워크에서는 대부분 막혀 있고, **규정 위반**일 수 있습니다.
